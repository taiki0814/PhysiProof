# Uniform Studio source

Adapted, with the user's authorization, from the friend's supplied ageru project.
Only the SVG renderer, safe browser image converter and administrator drawing UI
are retained. Their server, credentials, data files, ZIP, QA outputs, global CSS
and browser-only user persistence are not imported.

The renderer's garment geometry and fabrics are retained; external brand names
are not presented and signature brand tapes/Formstrip artwork are removed.
Models are registered as versioned definitions, not executable JS/SVG uploads.
PhysiProof shared Zod contracts/API authorization/storage remain authoritative.
