# Prefecture boundary data

`prefectureBoundaries.ts` is generated by `scripts/build-prefecture-boundaries.mjs`
from [piuccio/open-data-jp-prefectures-geojson](https://github.com/piuccio/open-data-jp-prefectures-geojson),
commit `513fb852832c99470e16b95a30ddd68bf3469dc0`.
The upstream administrative data is derived from Japan's National Land
Information Division. It is simplified for game-region identification (~20m),
not surveying or legal boundary determination. All polygons/holes/islands remain.
Border locations may need GPS reacquisition; gameplay territory limits are unchanged.
